# NARCH Spatial Evidence Workbench

A local-first workbench for spatial observation, evidence-aware design hypotheses, accessibility review, prioritization, and post-occupancy measurement.

**Live:** https://narch-advisory.vercel.app

## Repository contents

`index.html`, `privacy.html`, `robots.txt`, `sitemap.xml`, `terms.html`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
